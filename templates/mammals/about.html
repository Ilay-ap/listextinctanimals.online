{% trans "About the Project" %}

🎯 {% trans "Objective" %}

{% blocktranslate %}This digital catalog was developed as part of a Final Course Project (TCC) on ICT applied to biological memory conservation. The objective is to document and preserve information about extinct mammals since 1500, promoting awareness about the importance of biodiversity conservation.{% endblocktranslate %}

🌱 {% trans "Why does this matter?" %}

{% blocktranslate %}Species extinction is an irreversible process that results in the permanent loss of biodiversity. Since 1500, human activity has been the main cause of mammal extinction, through habitat destruction, overhunting, introduction of invasive species and climate change. Understanding these losses helps us prevent future extinctions and protect the species that still exist today.{% endblocktranslate %}

📚 {% trans "Methodology" %}

{% blocktranslate %}Data was collected from reliable scientific sources, including the IUCN Red List and academic publications. Each documented species includes information about habitat, geographic distribution and causes of extinction.{% endblocktranslate %}

🔬 {% trans "Technologies" %}

{% blocktranslate %}This project was developed using Django, a high-level Python web framework, with SQLite database for information storage.{% endblocktranslate %}
